# Robot

This project is to investigate using an LLM to control a simple robot, but creating a 'central nervous system' that provides real-time control over motors and sensors, and a 'higher brain function' controlled by the LLM.

Current hardware uses a Raspberry Pi, a MotorShield from https://github.com/sbcshop/MotorShield, and a TF-Luna Lidar for range-finding (https://thepihut.com/products/tf-luna-lidar-ranging-sensor). The code in this repo runs on the latest Raspberry Pi OS and is different from the code samples provided by the hardware manufacturers.
